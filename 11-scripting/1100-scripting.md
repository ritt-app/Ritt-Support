# Scripting

There are two possible ways to automate tagging and other operations with Ritt. 
- [Internal Scripting](/scripting-api/internal-scripting): Execute custom scripts (in Javascript syntax) within Ritt
- [External Scripting](/scripting-api/external-scripting): Perform custom actions by calling Ritt's localhost APIs from outside of Ritt
